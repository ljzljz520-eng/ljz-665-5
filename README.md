# 影院放映设备台账

管理影院 **放映机、音响、银幕、控制台** 四类设备的台账系统。纯 Node.js 内置模块实现，**零依赖、无需 npm install**，数据持久化到本地 JSON 文件。

## 快速启动

```bash
node server.js
# 打开 http://localhost:3000
```

默认端口 `3000`，可用环境变量修改：`PORT=8080 node server.js`

## 演示账号

| 角色 | 账号 | 密码 | 权限 |
|------|--------|----------|------------------------------|
| 管理员 | `admin` | `admin123` | 查询 + 新增 / 编辑 / 删除 / 模板下载 / 批量导入 |
| 普通员工 | `staff` | `staff123` | 仅查询（界面只读，服务端同样拦截写操作，返回 403） |

## 功能清单

- **台账管理**：字段 = 影厅、设备类别（放映机/音响/银幕/控制台）、品牌、序列号、责任人、状态（在用/闲置/维修中/报废）
- **查询筛选**：关键字模糊搜索 + 影厅 / 类别 / 状态下拉筛选 + 分页
- **权限控制**：登录鉴权（HMAC 签名 Token，12 小时有效）；管理员可维护，普通员工只读
- **数据校验**：必填、长度、枚举值、序列号全局唯一（含文件内去重）
- **批量导入**：
  - 下载 CSV 导入模板（UTF-8 带 BOM，Excel 直接打开不乱码）
  - 上传 CSV 导入（支持 UTF-8 / GBK 编码，支持引号包裹的逗号字段，可拖拽上传）
  - 逐行校验，**成功行入库、失败行跳过**，返回每行失败原因
  - **失败行一键下载**（CSV，附"失败原因"列，修正后可直接重新导入）

## API 一览

| 方法 | 路径 | 说明 | 权限 |
|--------|---------------------------|----------------------|--------|
| POST | `/api/login` | 登录，返回 token | 公开 |
| GET | `/api/me` | 当前用户 | 登录 |
| GET | `/api/meta` | 类别/状态/影厅枚举 | 登录 |
| GET | `/api/equipment` | 分页查询（keyword/hall/category/status/page/pageSize） | 登录 |
| POST | `/api/equipment` | 新增 | 管理员 |
| GET/PUT/DELETE | `/api/equipment/:id` | 详情 / 修改 / 删除 | 查询需登录，写需管理员 |
| GET | `/api/import/template` | 下载导入模板 CSV | 登录 |
| POST | `/api/equipment/import` | CSV 批量导入（body: `{content}`） | 管理员 |

## 导入模板格式

```csv
影厅,设备类别,品牌,序列号,责任人,状态
4号厅,放映机,Christie CP4455-RGB,CHR-2024-0088,赵敏,在用
```

- 表头必须完全一致（顺序、名称）
- 设备类别限：放映机 / 音响 / 银幕 / 控制台；状态限：在用 / 闲置 / 维修中 / 报废
- 序列号不可与已有数据或文件内其他行重复
