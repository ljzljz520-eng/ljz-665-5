# 影院放映设备台账系统

对影院 **放映机、音响、银幕、控制台** 四类设备进行台账管理，字段包括：**影厅、品牌、序列号、责任人、状态**。
支持角色分权（管理员维护 / 普通员工只读）、Excel 模板下载、批量导入与失败行下载。

## 快速启动

```bash
npm install
npm start
# 打开 http://localhost:3000
```

## 内置账号

| 角色 | 账号 | 密码 | 权限 |
|------|------|------|------|
| 管理员 | `admin` | `admin123` | 查询 + 新增/编辑/删除 + Excel 导入/模板/失败行下载 |
| 普通员工 | `staff` | `staff123` | 仅查询、导出台账（只读） |

> 权限在服务端逐接口强制校验（`requireAdmin`），前端隐藏按钮仅为体验优化。

## 功能清单

- **登录分权**：Session 会话，密码 scrypt 加盐哈希存储
- **台账查询**：关键字（品牌/序列号/责任人）+ 设备类型 / 影厅 / 状态组合筛选
- **设备维护**（管理员）：新增、编辑、删除；序列号全局唯一校验
- **Excel 导入**（管理员）：
  - `GET /api/import/template` 下载标准模板（含填写说明页）
  - `POST /api/import` 上传 `.xlsx`，逐行校验（必填、枚举、序列号唯一、文件内去重）
  - 通过的行入库，失败行生成清单，`GET /api/import/failed/:token` 下载（含失败原因列，保留 30 分钟）
- **台账导出**：`GET /api/equipment/export` 按当前筛选条件导出 `.xlsx`

## 导入模板列

| 列 | 必填 | 说明 |
|----|------|------|
| 设备类型 | ✅ | 放映机 / 音响 / 银幕 / 控制台 |
| 影厅 | ✅ | 如 1号厅 |
| 品牌 | ✅ | 可含型号 |
| 序列号 | ✅ | 平台内唯一 |
| 责任人 | ✅ | 负责人姓名 |
| 状态 | 可空 | 正常 / 维修中 / 备用 / 停用（默认正常） |

## 技术栈

Node.js + Express + express-session + multer + SheetJS(xlsx)；数据持久化为 `data/db.json`（原子写入），前端为原生 HTML/CSS/JS 单页应用。

## 目录结构

```
server.js          # 入口：鉴权中间件、REST API、导入导出
src/db.js          # 数据层：用户/设备 CRUD、枚举、种子数据
src/excel.js       # Excel：模板生成、导入解析、失败行/导出工作簿
public/            # 前端单页应用（index.html / app.js / styles.css）
data/db.json       # 运行后自动生成的数据文件（已 gitignore）
```
